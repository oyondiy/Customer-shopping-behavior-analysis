# Customer Shopping Behavior Analysis

## Overview
This project analyzes customer shopping behavior to help a retail company improve sales, engagement, and loyalty.  
The analysis covers product categories, discounts, promotions, demographics, and seasonal trends.

**Tools used:** Python (Jupyter Notebook), SQL (MySQL), Power BI

![Customer Shopping Dashboard](screenshots/customer.png)

---

## Dataset
- ~3,900 customers  
- Total revenue: $233,080  
- Average purchase: $59.76  
- Columns include: age, gender, purchase amount, product category, discount, season, rating, etc.

---

## Key Insights
- Middle‑aged males generate highest revenue ($46.6K)  
- Clothing drives >45% of total revenue  
- Discounts do **not** increase average order value  
- Fall is the peak season  
- Review ratings have weak link to repeat purchases  

---

## Business Recommendations
- Replace discounts with bundling or loyalty programs  
- Focus on middle‑aged/adult males and high‑spending young adult females  
- Optimize inventory for Fall, promote more in Summer  
- Expand into top performing states (Montana, Idaho)
